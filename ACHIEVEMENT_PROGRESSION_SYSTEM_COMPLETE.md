## 📝 Usage Examples

### **Basic Usage**
```python
# Initialize the integrated system
integration = AchievementProgressionIntegration()

# Process a game event
event = GameEvent(
    player_id="player123",
    event_type=IntegrationEventType.COMBAT_VICTORY,
    event_data={"enemies_defeated": 1, "damage": 150}
)
await integration.process_game_event(event)

# Get player dashboard
dashboard = integration.get_player_dashboard("player123")
```

### **Custom Achievement Creation**
```python
# Create a custom achievement
await integration.achievement_system.create_custom_achievement(
    creator_id="admin",
    achievement_data={
        "name": "Dragon Slayer",
        "description": "Defeat 10 legendary dragons",
        "type": "combat",
        "rarity": "legendary",
        "progress_type": "count",
        "target_value": 10
    }
)
```

### **Challenge Participation**
```python
# Join a daily challenge
participation = await integration.challenge_system.participate_in_challenge(
    player_id="player123",
    challenge_id="daily_combat_trial"
)
```
