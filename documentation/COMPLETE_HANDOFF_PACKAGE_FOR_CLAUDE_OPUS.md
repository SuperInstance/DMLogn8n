## How to Get Most Value from Opus Sessions

### Before Each Session

1. **Know what puzzle you're solving**
   - Have specific question in mind
   - Don't go in vague

2. **Share relevant context**
   - Include just enough documentation
   - Too much context wastes tokens on familiar material
   - Too little context wastes time on clarification

3. **State your strategic priority**
   - "I want to optimize for player experience"
   - "I want to minimize implementation complexity"
   - "I want maximum fidelity"
   - This guides Opus's recommendations

### During Session

1. **Ask clarifying questions**
   - "What assumptions are you making?"
   - "What would break this approach?"
   - "How does this affect other components?"

2. **Push back on weak reasoning**
   - "Why is that the only option?"
   - "What's the trade-off?"
   - "Is there a better way?"

3. **Request specific artifacts**
   - "Create a decision matrix"
   - "Show the dependency graph"
   - "What are the failure modes?"

4. **Take notes on key insights**
   - These become architectural decisions
   - Reference in future conversations

### After Each Session

1. **Document the decision**
   - Why this approach
   - What trade-offs accepted
   - When to reconsider

2. **Identify next conversation**
   - What puzzle does this unlock?
   - What sub-puzzles emerged?
   - What contradicts this decision?

3. **Check consistency**
   - Does this align with other decisions?
   - Do we need to revisit earlier puzzles?
   - What new puzzles emerged?

### Token Efficiency
- Share entire document chunks (they compress well)

- Opus can suggest order of attack

- Ask for creative alternatives
- Request adversarial perspective

- Identify contradictions early
