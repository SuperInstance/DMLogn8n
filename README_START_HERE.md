## 💡 The Big Picture

DMLog is an AI system that lets D&D characters learn from gameplay. Instead of static NPCs, characters improve over time through a process:

```
Gameplay
  → Decisions logged
  → Outcomes tracked
  → Patterns extracted
  → Neural network fine-tuned
  → Character improves
  → Next session, better decisions
```

All of this happens automatically between sessions without requiring manual training data.

**Current Status:** Foundation complete, learning engine 20% complete, strategic direction set.

**Next Step:** Finish Phase 7 learning pipeline (3-4 weeks), then expand to multi-character learning.
